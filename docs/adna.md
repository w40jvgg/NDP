# ADNA — Audio DNA

## Назначение

ADNA — термин NDP для перцептивного цифрового отпечатка звука. Он отвечает на вопрос «что это за звук?» и архитектурно отделён от прав, платежей и UI.

## V1

Целевая модель: 256 bytes; при JSON-передаче — base64. Текущая статическая сборка использует `DemoFingerprintEngine`, а не реальный перцептивный алгоритм.

## V2 target

Архитектура допускает `offset_sec`, `coverage_q`, `scale`, `attribution` для фрагментного поиска и нескольких источников. Эти возможности не заявлены как реализованные в текущем demo.

## SimilarityPolicy

Единственный источник demo-порогов — `service/core/config.js`:
- SAME: `>= 0.90`
- DERIVATIVE: `>= 0.75`
- DIFFERENT: `< 0.75`

UI не должен трактовать эти вердикты как юридическое доказательство плагиата или нарушения авторских прав.

## Upload

Demo frontend ограничивает файл 32 MiB и проверяет расширение/MIME. Production server обязан дополнительно выполнять сигнатурную проверку, decoder validation, timeout/CPU limits, rate limiting и безопасные temp files.
